# README
## ISTL-Sports-Engine
The Italian Supreme Tennis League (ISTL - that is a fictional organization) wants to unify and streamline the management
of racquet based tournaments, including but not limited to tennis, padel, table tennis and similar sports.

## Versions
Ruby = 3.4.8
Rails = 8.1.1

## Create Rails structure
``` bash
rails new . --database=postgresql --skip-kamal --skip-solid --skip-ci --skip-thruster
```
