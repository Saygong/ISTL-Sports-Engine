# README
## ISTL-Sports-Engine
The Italian Supreme Tennis League (ISTL - that is a fictional organization) wants to unify and streamline the management of racquet based tournaments, including but not limited to tennis, padel, table tennis and similar sports.


This application has been built and tested using the following tools' version.

## Versions
Ruby = 3.4.7

Sqlite3 = 3.51.1 <br>
Rails = 8.1.1
